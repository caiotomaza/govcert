GovCert
Auditoria de IA e Governança Pública — Configurações da Extensão
Endereço do servidor Laravel. Padrão: http://localhost:8000
Gere um token em: Perfil → API Tokens no sistema web.
Usado para identificar quem gerou os logs na auditoria.

A extensão monitora apenas as plataformas de IA configuradas no manifesto.
Nenhum dado é enviado sem um token válido configurado.
